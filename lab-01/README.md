## Перевірка вебпроєкту

1. Завантажити репозиторій через Code → Download ZIP, розпакувати.
2. Відкрити `index.html` у браузері.
3. Натиснути кнопку «Тема» та перевірити перемикання оформлення.
4. Натиснути «Вебпроєкт»: показано 2 картки; «Дані»: 1 картка; «Усі»: 3 картки.
5. Перевірити відображення на вузькому екрані.
6. За потреби переглянути зміни у вкладці Commits та Pull Requests.
