## Мій вебпроєкт

**Особисте навчальне портфоліо** — адаптивна українськомовна вебсторінка з інформацією про студентку, технології, лабораторні роботи та історію версій.

Реалізовано:
- адаптивне оформлення для комп'ютерів, планшетів і телефонів;
- перемикання світлої та темної теми;
- фільтрацію карток лабораторних робіт (усі, вебпроєкт, дані);
- семантичну HTML-структуру, доступні кнопки й навігацію;
- окрему гілку розробки та об'єднання змін через Pull Request.

### Запуск

Оберіть **Code → Download ZIP**, розпакуйте архів та відкрийте `index.html` у браузері. Установлення залежностей не потрібне. Вебпроєкт працює без сервера.

### Приклади перевірки

1. Натисніть **Тема** — змінюється оформлення сторінки.
2. Натисніть **Вебпроєкт** — залишаються дві відповідні картки.
3. Натисніть **Дані** — показується картка з `sales.csv`.
4. Натисніть **Усі** — знову видно всі три картки.
5. Зменште вікно браузера — картки перебудовуються в одну колонку.
