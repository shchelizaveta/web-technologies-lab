## Призначення репозиторію

Репозиторій для завантаження та зберігання лабораторних робіт з вебтехнологій.

## Структура

- `index.html` — головна HTML-сторінка.
- `style.css` — стилі сторінки.
- `images/` — папка для графічних матеріалів.
- `sales.csv` — навчальний набір даних (додається окремо).

## Робота з GitHub

Основна гілка — `main`. Зміни сторінки виконуються в гілці `development` і переносяться в `main` через Pull Request.
