## Контрольні питання

1. **Що таке Git?** Розподілена система контролю версій для відстеження змін у файлах.
2. **Що таке GitHub?** Онлайн-платформа для розміщення Git-репозиторіїв та спільної роботи над ними.
3. **Що таке репозиторій?** Сховище файлів проєкту разом з історією змін.
4. **Для чого використовується GitHub?** Для зберігання коду, контролю версій, співпраці та обговорення змін.
5. **Що таке commit?** Збережений стан змін у репозиторії з автором, датою та повідомленням.
6. **Що таке branch?** Окрема лінія розробки, у якій можна працювати незалежно від інших гілок.
7. **Для чого потрібна гілка main?** Для зберігання основної версії проєкту.
8. **Що таке clone?** Створення локальної копії віддаленого Git-репозиторію.
9. **Що робить команда git add?** Додає зміни до індексу для наступного коміту.
10. **Що робить команда git commit?** Фіксує підготовлені зміни в історії локального репозиторію.
11. **Для чого використовується git push?** Для передавання локальних комітів у віддалений репозиторій.
12. **Для чого використовується git pull?** Для отримання і інтеграції змін із віддаленого репозиторію.
13. **Що таке Pull Request?** Запит на перегляд і внесення змін однієї гілки до іншої.
14. **Що таке Merge?** Об'єднання історії або змін двох гілок.
15. **Для чого використовується README.md?** Для опису проєкту, його структури та правил використання.
16. **Чим Git відрізняється від GitHub?** Git — система контролю версій, а GitHub — сервіс для розміщення Git-репозиторіїв.
